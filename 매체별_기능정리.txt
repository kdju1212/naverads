매체별 Claude 도구(MCP)로 할 수 있는 것 — 2026-11-22 기준 운영 배포본
Claude 커넥터: https://naverads-api.djkim0509.workers.dev/mcp ("네이버광고")
※ 괄호 안 영어는 Claude가 부르는 도구 이름. 사용자는 그냥 말로 물어보면 된다.

공통 규칙
- 바꾸는 작업은 항상: Claude가 채팅에 표(대상·지금 값 → 바뀔 값)로 보여 줌 → Claude 화면 '허용' 버튼 → 실행
- 하루예산이 늘 수 있는 변경(캠페인 켜기·예산 올리기 등)은 따로 막거나 웹 승인을 받는다
- 계정별 '클릭당 최대 입찰가'를 넘는 입찰가는 서버가 막는다
- 광고 데이터는 서버에 쌓지 않고, 물어볼 때마다 각 매체에서 바로 가져온다

1. 네이버 검색광고 — 조회·수정·등록 모두 (실계정 확인됨)
==================================================================
[조회]
- 계정·조직 목록 (list_ad_accounts)
- 성과: 계정·상품별 합계(get_performance), 일별(get_daily_performance),
  키워드·광고그룹·소재별(get_entity_performance), 시간대·요일·지역·PC/모바일별·오늘 실시간(get_stats)
- 구조: 캠페인(list_campaigns), 광고그룹(list_adgroups), 키워드(list_keywords), 소재(list_ads),
  확장소재(list_ad_extensions), 비즈채널(list_channels), 제외검색어(list_negative_keywords),
  확장검색 제외검색어(list_exp_negative_keywords)
- 타기팅(요일·시간·지역·기기·연령·성별)(get_targeting), 노출 매체(get_media_target)
- 대용량 보고서: 검색어·쇼핑 검색어·전환·타기팅별 등(request_stat_report → get_stat_report)
- 연관 키워드·월간 검색수(related_keywords), 입찰가 예측(estimate_bid)
- 검수 결과·반려 사유(get_inspect_history), 비즈머니 잔액·내역(get_bizmoney)
- IP 차단 목록(list_ip_exclusions), 작업 기록(list_audit_logs)
- 광고비 안전장치 상태(get_ad_safety), 웹 승인 결과(get_approval), 자동입찰 규칙(list_auto_bids)
- 지금 순위(check_ranks) — Cloudflare 서버에선 순위를 못 읽어 사실상 안 됨

[수정·등록]
- ON/OFF·입찰가·하루예산 변경, 캠페인·광고그룹·키워드·제외검색어 등록·삭제
  (preview_changes 미리보기 → execute_job 실행, schedule_job 예약 실행)
- 파워링크 소재 등록(create_ad), 쇼핑 상품소재 등록(create_shopping_ad), 소재 복사(copy_ads)
- 확장소재 등록·삭제(create_ad_extension, delete_ad_extension)
- 타기팅 변경(set_targeting), 노출 매체 변경(set_media_target), 키워드별 연결 URL(set_keyword_url)
- 확장검색·ADVoost Max 끄기(set_adgroup_options), 확장검색 제외검색어 등록·삭제
- 자동입찰(목표 순위 맞추기) 설정·삭제·즉시 실행(set_auto_bid, delete_auto_bid, run_auto_bids)
- IP 차단·해제(add_ip_exclusion, delete_ip_exclusion)
- 웹사이트 비즈채널 등록·재검수(create_site_channel, reinspect_channel), 키워드·소재 재검수(request_inspect)
- 긴급 중지(stop_ad): 승인 없이 바로 끔
- 플레이스광고(가게 광고): 상태 보기·계획·적용·취소(place_ads_status/plan/apply/cancel)

[웹 승인이 필요한 것] 캠페인 하루예산 올리기, 캠페인 켜기, ADVoost 켜기
  → Claude가 승인 주소를 주고, 웹에서 승인하면 실행(관리자가 계정별로 'Claude에서 바로 실행'을 켜면 바로 실행)

[안 되는 것] 타기팅 입찰 가중치, ADVoost Max 켜기, 확장소재 전화·이미지 유형, 쇼핑몰·플레이스 비즈채널 등록,
  파워콘텐츠·브랜드검색, 엑셀 대량 등록, 비즈머니 충전·환불(네이버 API에 없음)

2. 구글 광고 — 조회 전부 + 수정·등록 대부분 (실계정 미확인)
==================================================================
[준비 필요] 서버에 구글 개발자 토큰(GOOGLE_ADS_DEVELOPER_TOKEN), 웹 설정에서 구글 계정 연결(관리자),
  수정하려면 설정에서 계정별 클릭당 최대 입찰가 입력. 관리자만 쓸 수 있다.

[조회]
- 보고서·설정 전부(google_ads_search, 구글 조회 문장 GAQL):
  캠페인·광고그룹·키워드·광고별 성과, 검색어 보고서, 시간·요일·기기·지역·연령·성별,
  품질평가점수, 노출 점유율(예산·순위로 놓친 노출), 경쟁사 비교, 예산 제한·광고 거부 사유,
  변경 기록(30일), 추천사항·최적화 점수, 고객 목록, 자산, PMax·쇼핑·동영상 성과 (한 번에 200행)
- 전환 액션 설정과 액션별 전환·마지막 전환일(get_google_conversions)
- 키워드 플래너: 추천 키워드·검색량·상단 입찰가(google_keyword_ideas)
- 잠재고객 인사이트: 관심사 찾기, 구성, 타기팅 추천, 겹침, 도달 규모(google_audience_insights)
- 광고 미리보기 링크 — PMax만(google_ad_preview)
- 새 캠페인 추천: 예산·키워드·입찰 전략·사이트링크(google_generate_recommendations)
- 그 밖의 조회 전부(google_ads_read): 키워드 월별 검색량 추이·예측·광고그룹 묶음, 도달 계획(유튜브),
  업종 벤치마크, 유튜브 크리에이터·트렌드, 지역 이름→ID, 브랜드·키워드 주제 찾기, 스마트 캠페인 제안,
  접근 가능 계정 목록, 청구서, 결제 계정, 신원 확인 상태, 작업 상태

[수정·등록] (google_ads_change: 먼저 구글 검사 → 표 → 실행)
- 켜기·끄기(캠페인 켜기는 제외), 입찰가, 예산 내리기, 입찰 전략
- 키워드·제외 키워드, 반응형 검색광고, 사이트링크·콜아웃·전화, 타기팅(지역·시간·기기·잠재고객)
- 캠페인 만들기(검색·디스플레이·PMax·쇼핑·동영상, 꺼진 상태로만)
- 추천 적용(예산 추천 제외), 클릭 전환 업로드
- 고객 목록 만들기·업로드(google_customer_match, 이메일·전화를 암호값으로 바꿔 보냄)

[막아 둔 것] 캠페인 켜기, 켜진 채로 캠페인 만들기, 예산 올리기, 캠페인 예산 바꿔 끼우기, 예산 추천 적용
  → 구글 광고 화면에서 직접 (구글용 웹 승인은 아직 없음)

[안 되는 것] 이미지·동영상 올리기, 전환 수정·전화 전환·매장 판매 업로드, 하위 계정·사용자 초대·결제 설정,
  실험 시작·반영, 일괄 작업(batch job), 소재 자동 생성
[주의] 최대 입찰가 검사는 기본 입찰가만 본다(기기·지역 배율, CPM·CPV 입찰은 안 봄)

3. 메타(페이스북·인스타그램) 광고 — 조회만 (실계정 미확인)
==================================================================
[준비 필요] 웹 설정에서 광고계정 ID + 시스템 사용자 토큰(ads_read 권한) 연결. 관리자만 쓸 수 있다.

[조회]
- 3매체 나란히 비교: 네이버·메타·구글 비용·전환·ROAS(get_cross_channel_performance)
- 메타 조회 전부(meta_ads_search, 메타 API 그대로, 한 번에 200행):
  캠페인·광고세트·광고별 성과, 일별, 나이·성별·게재 위치(피드·스토리·릴스)·지역·기기별,
  구매·장바구니·결제 시작·리드 전환, 도달·빈도·CPM, 광고 순위 진단(품질·참여율·전환율)
  광고 목록·상태·예산, 소재(문구·이미지), 검토 거부 사유, 픽셀 마지막 수신,
  지출 한도·잔액, 변경 기록, 맞춤 타겟·맞춤 전환 목록, 예상 도달 규모, 광고 미리보기
  관심사·지역 찾기, 내 광고계정 목록, 큰 보고서(만들어 두고 나중에 받기)
- 토큰에 권한이 있어야 나오는 것: 리드 양식 응답, 페이지 게시물 성과, 카탈로그,
  광고 라이브러리(경쟁사 광고, 메타 신원 확인 필요)

[수정·등록] 없음 — 켜기·끄기, 예산, 광고 만들기, 타겟 만들기, 전환 API(CAPI) 보내기 모두 보류
