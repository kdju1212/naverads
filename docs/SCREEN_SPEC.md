# 화면 명세 — MVP v1.0 (AGENCY 우선)

> 최종 갱신: 2026-10-18. PC 운영자 중심, 한국어·KRW·Asia/Seoul.

## 공통 레이아웃
- **왼쪽 메뉴:** 대시보드 / 캠페인 / 광고그룹 / 키워드 / 소재·상품소재 / 확장소재 / 대량 작업 / 작업 이력 / 설정
- **상단 바:**
  - 광고 계정 선택기 — **다중 선택**(검색, 전체 선택, 담당 계정만 보기). 권한 없는 계정은 목록에 나오지 않는다.
  - 광고 유형: 전체 / 파워링크 / 쇼핑검색
  - 기간 선택
  - 동기화 상태(계정별 마지막 동기화 시각, 오류 배지)
- **테이블 공통:** 빠른 검색, 필터, 정렬, 체크박스 다중 선택, 컬럼 첫 열에 "광고주(계정)" 표시, 지원 필드 인라인 수정. 인라인 수정도 즉시 반영하지 않고 대량 작업 미리보기로 모은다.

## 1. 메인 대시보드 (P0)
| 영역 | 내용 |
|---|---|
| 요약 카드 | 연결된 광고 계정 수, 전체 광고비, 전체 전환수, 전체 ROAS |
| 계정별 성과 표 | 광고주명, 광고비, 클릭, 전환수, 매출, ROAS — 파워링크/쇼핑검색 분리 컬럼. 미제공 값은 `-`, 0과 구별 |
| 최근 대량 작업 | 작업명, 실행자, 상태(완료/부분 실패/실패), 성공·실패 건수 → 상세 이동 |
| 동기화 오류·실패 작업 | 동기화 실패 계정, 실패 행이 남은 작업 → 재실행 버튼 |

## 2. 캠페인 (P0)
- 선택한 여러 계정의 캠페인 통합 목록. 컬럼: 광고주, 유형, 캠페인명, 상태, 일예산, 기간 성과.
- 일괄 작업: ON/OFF, 일예산 수정(정액 지정) → 미리보기.
- P1: 다른 계정으로 복사.

## 3. 광고그룹 (P0)
- 통합 목록. 컬럼: 광고주, 유형, 캠페인, 광고그룹명, 상태, 기본 입찰가.
- 일괄 작업: ON/OFF, 기본 입찰가 수정 → 미리보기.

## 4. 키워드 — 파워링크 전용 (P0)
- 광고 유형 필터가 "쇼핑검색"이면 메뉴를 비활성화하고 "쇼핑검색은 상품소재 단위로 관리합니다" 안내.
- 목록: 광고주, 광고그룹, 키워드, 상태, 입찰가(그룹 입찰가 사용 여부).
- 대량 등록(붙여넣기/엑셀), ON/OFF, 입찰가 수정, 중복 검사.

## 5. 소재·상품소재 (P0) — 탭 분리
- **파워링크 소재 탭:** 제목·설명·URL, 검수 상태, ON/OFF. 제목/설명 수정은 신규 등록 → 검수 확인 → 기존 소재 OFF 흐름(공식 API 확인 필요).
- **쇼핑 상품소재 탭:** 상품명, 상품 ID, 상태, 검수 상태, 입찰가, 성과. ON/OFF·입찰가 대량 수정. 상품 원본 정보는 수정하지 않는다.

## 6. 확장소재 (P0, 파워링크만)
유형별(서브링크·추가제목·추가설명·홍보문구·이미지) 목록·ON/OFF. 공식 API 지원 범위 확인 후 구현.

## 7. 대량 작업 (P0)
1. **입력:** 목록에서 선택 후 일괄 변경, 또는 엑셀 업로드(템플릿 다운로드 제공)
2. **미리보기:** 광고주별로 그룹핑된 변경 전→후 표. 오류 행은 빨간색 + 사유. 상단에 "계정 N개 · 변경 M건 · 오류 K건".
3. **실행:** 오류 없는 행만 실행. 실행 직전 권한 재검증.
4. **결과:** 행별 성공/실패/오류 메시지, 실패 행 엑셀 다운로드, **실패 행만 재실행**(P1).

## 8. 작업 이력 (P0)
- 감사 로그: 시각, 담당자, 광고주, 객체, 항목, 변경 전→후, 작업 ID.
- 필터: 담당자, 광고주, 기간.
- P1: 선택 이력 "되돌리기" → 역방향 대량 작업 미리보기 생성.

## 9. 설정 (P0)
- **광고 계정 연결:** API 자격증명 등록(비밀키는 저장 후 다시 표시하지 않음) → 고객 ID 입력 → 연결 검증 → 연결. 해제 확인 모달.
- **직원 관리:** 직원 초대, 역할(OWNER/ADMIN/MEMBER).
- **담당 계정 배정:** 직원 × 계정 매트릭스, 셀 값 없음/VIEW/EDIT.
- **구독:** 플랜, 체험 종료일, 과금 대상 계정 수 × 단가 표시(결제 연동 없음).

## P2 (MVP 이후, `DIRECT_ADVERTISER`)
초보자용 간단 화면, 성과 해석 문구, 입찰·예산 가이드, 생성 마법사. 같은 API를 사용하고 화면만 분기한다(`workspaces.type`).
