# 공통: 주소·인증·서명·호출 제한

조사일 2026-11-08. 출처: 공식 문서 사이트의 안내·샘플 페이지(gh-pages `assets/i18n/markdown-ko-KR.json`, `markdown-en-US.json`), 공지 2020-12-18, 2025-10-30, 2026-07-02.

## 1. 호출 주소

- 서비스 주소: `https://api.searchad.naver.com` (공식 안내 'Service URL')
- 경로는 공식 문서 표기 그대로 쓴다(예: `/ncc/campaigns`, `/stats`, `/keywordstool`).
  명세 JSON 안의 경로 일부는 `/api/ncc/...`처럼 `/api`가 붙어 있지만, 공식 문서 주소·샘플·릴리스 노트는 모두 `/api` 없이 쓴다. 이 문서도 `/api`를 뺀다.
- 경로 끝의 `{?ids}` 같은 표기는 "이 쿼리 파라미터를 붙여 부른다"는 뜻이다. 실제 호출은 `GET /ncc/campaigns?ids=...`.

## 2. 키 발급 (광고주가 할 일)

1. 네이버 검색광고 광고주센터에 로그인한다.
2. 광고 시스템 → 도구 → **API 사용 관리**에서 API 서비스를 신청한다.
3. 발급되는 값 세 가지
   - **API 라이선스(`API-KEY`)**: 모든 요청 헤더에 넣는다.
   - **비밀키(`API_SECRET`)**: 서명을 만들 때만 쓴다. 요청에 직접 넣지 않는다.
   - **광고 계정 번호(Customer ID)**: 어느 광고 계정을 다룰지 `X-Customer` 헤더로 보낸다.

> 2026-07-02 공지: 계정 통합 뒤 일부 Agent의 비밀키가 바뀐 사례가 있었다. "비밀키가 바뀌었다"는 응답을 받으면 광고주센터에서 새 키를 확인하거나 다시 발급해 적용한다.

## 3. 서명 만들기

공식 생성식:

```
sha256-hmac( API_SECRET, 타임스탬프 + "." + HTTP메서드 + "." + 요청 URI )   → Base64
```

- 타임스탬프: 유닉스 시간 밀리초(예: `1457082455307`)
- 공식 예시 문자열: `1457082455307.GET./ncc/campaigns`
- 공식 예시는 경로만 쓴다. **쿼리 문자열을 서명에 넣는지는 공식 안내에 명시돼 있지 않다**(미확인). 이 프로젝트 구현(`backend/src/app/naver.py`)은 경로만 서명하고 실제로 동작한다.

## 4. 요청 헤더 (모든 엔드포인트 공통)

| 헤더 | 값 |
|---|---|
| `X-Timestamp` | 서명에 쓴 타임스탬프(밀리초) |
| `X-API-KEY` | API 라이선스 |
| `X-Customer` | 다룰 광고 계정 번호 |
| `X-Signature` | 위에서 만든 서명 |
| `Content-Type` | 본문이 있으면 `application/json` (한 번만. 2025-10-30 공지: 2025-12-01부터 대용량 보고서 호출 시 Content-Type 중복이면 실패) |

예시(가상값):

```http
GET /ncc/campaigns HTTP/1.1
Host: api.searchad.naver.com
X-Timestamp: <밀리초 타임스탬프>
X-API-KEY: <API 라이선스>
X-Customer: <광고 계정 번호>
X-Signature: <서명>
```

[03-endpoints.md](03-endpoints.md)의 요청 예시는 이 네 헤더를 "공통 인증 헤더" 한 줄로 줄여 적었다.

## 5. 호출 제한

- 공식 문서에 엔드포인트별 숫자 한도는 **없다**(미확인).
- 2020-12-18 공지: 사용량 제한은 "호출 대상 계정당 속도 제한"이고, 넘으면 `429 Too Many Requests`. **키워드 도구(`/keywordstool`)는 다른 기능의 1/5~1/6 속도**이며 IP 단위로도 제한된다. 429가 오면 더 길게 쉬었다가 다시 부르고, 429가 몰리면 최소 5분 멈추라고 안내한다.
- 공식 오류 코드표: `1016 너무 많은 접속을 시도하였습니다`.
- 대용량 보고서·마스터 보고서는 비동기 작업이라 상대적으로 느리다(같은 공지).

## 7. 보안 주의 (서비스 운영)

- 비밀키·API 라이선스·광고 계정 번호는 문서·로그·화면 캡처에 남기지 않는다.
- 비밀키는 서명에만 쓰고 네트워크로 보내지 않는다.
