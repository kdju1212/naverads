네이버 광고 통합 관리 — 작업 정리 (2026-10-18 기준)
================================================================

사이트:  https://naverads.djkim0509.workers.dev
API:     https://naverads-api.djkim0509.workers.dev/docs
저장소:  https://github.com/kdju1212/naverads (main)


■ 한 것
----------------------------------------------------------------

[배포]
- Cloudflare Workers Builds에 GitHub 연결 → 프론트엔드·백엔드 모두 push하면 자동 배포
- 확인 방법: GitHub 커밋의 "Workers Builds: naverads", "Workers Builds: naverads-api" 둘 다 성공 후 테스트
  (프론트가 먼저 배포되면 잠깐 "Not Found", "알 수 없는 유형" 같은 오류가 날 수 있음)
- 백엔드 Secret APP_SECRET 설정 확인됨 (네이버 비밀키 암호화 저장에 사용)

[계정 연결]
- 네이버 검색광고 API 키 등록 + 실계정(CUSTOMER_ID) 연결·동기화 성공
- 설정 화면 표기 "고객 ID" → "CUSTOMER_ID"

[조회 (동기화)]
- 캠페인, 광고그룹, 키워드, 소재
- 반응형 검색광고(RSA_AD) 소재: 파워링크 탭에 표시, 제목·설명(assets)까지 저장
- 확장소재: 파워링크 캠페인·광고그룹의 확장소재 동기화 + 확장소재 화면
- 성과 통계: 캠페인별 일별 30일(어제까지) — 노출·클릭·비용(VAT 포함)·전환
  ※ 현재 값이 모두 0. 소재가 검수 중이라 노출이 없어서인지 네이버 화면과 비교 필요

[실계정 수정 — 모두 실제 호출로 성공 확인]
- ON/OFF: 캠페인, 광고그룹, 키워드, 소재, 확장소재
- 키워드 입찰가, 광고그룹 기본 입찰가, 캠페인 일예산
- 수정 후 네이버 응답에 값이 반영됐는지 비교 → 안 됐으면 "반영되지 않았습니다"로 실패 처리

[확장소재 생성·삭제]
- 새로 만들기: 추가설명(제목+설명), 서브링크(이름 | URL) — 매일 24시간 노출, 광고그룹 비즈채널 사용
  ※ 생성 1건 성공(ID 발급)했으나 20분 뒤 네이버 목록에서 사라짐 — 원인 미확인
- 삭제: 선택 삭제(확인 창). 네이버에 이미 없으면 앱 목록에서만 정리하고 이력에 "네이버에 이미 없음"
  ※ 실제로 존재하는 확장소재를 지우는 경우는 아직 확인 못 함
- 내용 수정: 네이버 API가 지원하지 않음(수정 가능 필드는 userLock, period뿐) → 새로 만들고 기존 것 삭제

[기타]
- 이력 화면에 생성·삭제 표시, 대량 작업 엑셀 안내에 ad_extension 추가
- 백엔드 테스트 6개 통과


■ 지금 계정에 남아 있는 테스트 값 (켜기 전에 확인)
----------------------------------------------------------------
- 캠페인 "자하라밤_브랜드": OFF, 일예산 50,000원 (원래 300,000원)
- 캠페인 "자하라밤_파워링크": OFF (테스트 전부터 OFF)
- 광고그룹 grp-a001-01-000000069500026: OFF, 입찰가 10,000원 (원래 70원) ← 켜기 전 꼭 되돌리기
- 키워드 nkw-a001-01-000008349919072: OFF, 입찰가 500원 (원래 950원)


■ 할 것
----------------------------------------------------------------
1. 확장소재 생성·삭제 재확인
   - 새로 만들고 바로 삭제해서 실제 삭제가 되는지 확인
   - 만든 확장소재가 사라진 원인 확인 (네이버 화면에 보였는지)
   - 서브링크 만들기 실계정 테스트
2. 성과 통계 확인 — 노출이 생긴 뒤 네이버 화면 숫자와 비교
3. 엑셀 신규 등록 (네이버 대량 관리처럼 키워드·소재·확장소재)
   - 사용하는 네이버 대량 관리 엑셀 양식 파일 필요
4. 쇼핑 소재 입찰가 — 쇼핑검색 계정 연결 후
   (명세상 수정 필드에 없고 응답에도 값이 안 와서 실호출로 확인 필요)
5. 대시보드
6. 확장소재 생성 유형 추가 (추가제목, 홍보문구 등 — 실데이터로 구조 확인 후)
7. 동기화 시 네이버에서 사라진 항목을 앱 목록에서도 정리
8. 무료 플랜 CPU 한도 — 광고그룹이 많으면 동기화가 중간에 끊길 수 있음
