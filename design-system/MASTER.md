# 디자인 시스템 — 네이버 광고 통합 관리

업무용 B2B SaaS. 마케터가 하루 종일 켜 두고 표를 보고, 계정을 바꾸고, 걸러서, 한 번에 바꾸는 도구다.
기준: 네이버 검색광고 관리자·Google Ads의 실무 흐름 + Stripe Dashboard의 정돈된 화면.

- 코드 토큰: `frontend/app/globals.css` (`@theme`) — 색은 Tailwind 클래스로 쓴다 (`bg-primary`, `text-muted`, `border-line` …)
- 페이지별 예외가 생기면 `design-system/pages/<페이지>.md`에 적고, 그 파일이 이 문서보다 우선한다.
- 근거: ui-ux-pro-max `--design-system` (스타일 "Minimalism & Swiss", 밀도 8/10, 움직임 2/10).
  도구가 준 색(파랑+주황 CTA)·글꼴(Plus Jakarta Sans, 한글 없음)·랜딩 패턴은 이 제품에 맞지 않아 쓰지 않았다.

## 1. 원칙

1. **데이터가 주인공** — 장식보다 숫자와 상태. 카드·그림자·색은 의미가 있을 때만.
2. **조작이 빠르게** — 계정 전환, 필터, 선택 → 일괄 작업이 항상 같은 자리에 있다.
3. **상태는 모양으로도** — 색만으로 구분하지 않는다(점·글자·아이콘 같이).
4. **조용하고 일정하게** — 같은 역할은 같은 모양. 화려한 그라데이션·큰 히어로·이모지 아이콘 없음.
5. **실수에 강하게** — 바꾸기 전 미리보기, 위험한 작업은 빨간색 + 확인.

## 2. 색

라이트 모드만 지원(업무용, 다크 모드는 만들지 않음).

## 3. 글꼴

- **Pretendard** (한글·영문·숫자 한 벌, 국내 업무용 표준). 없으면 시스템 글꼴.
  `"Pretendard Variable", Pretendard, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif`
- 숫자가 세로로 줄 서는 곳(표·KPI·금액)은 `tabular-nums`, 오른쪽 정렬.
- 크기 단계 (이것만 쓴다):

| 이름 | 크기/줄 높이 | 굵기 | 쓰임 |
|---|---|---|---|
| caption | 12 / 16 | 500 | 배지, 캡션, 표 보조 정보 |
| body-sm | 13 / 20 | 400 | 표 셀, 입력, 버튼 |
| body | 14 / 22 | 400 | 일반 본문, 설명 |
| title-sm | 15 / 22 | 600 | 패널 제목 |
| title | 20 / 28 | 700 | 페이지 제목 |
| kpi | 24 / 32 | 700 | 대시보드 핵심 숫자 |

## 4. 간격·크기·모서리

- 4px 단위: 4 · 8 · 12 · 16 · 20 · 24 · 32. 페이지 여백 24, 패널 안 16, 컨트롤 사이 8.
- 높이: 컨트롤(버튼·입력·선택) **32px**, 작은 컨트롤 28px, 표 행 **40px**(촘촘 모드 32px).
- 모서리: 컨트롤 6px, 패널·표·팝오버 8px, 배지 4px. 전부 둥글게 하지 않는다.
- 그림자: 패널은 테두리만. 팝오버·드롭다운·토스트만 `0 4px 12px rgb(15 27 45 / .08)`.
- 움직임: hover·열고 닫기 150ms ease-out. 그 이상 애니메이션 없음, `prefers-reduced-motion`이면 끔.

│            ├───────────────────────────────────────────────────────┤
│ 대시보드     │ 페이지 제목                              [주 동작 버튼]  │

- 메뉴 그룹: **성과** (대시보드) / **광고 관리** (캠페인·광고그룹·키워드·키워드 등록·자동입찰·소재·확장소재) /
  **작업** (엑셀 대량 작업·작업 결과) / **도구** (UTM 빌더) / **관리** (변경 이력·설정).
- 계정 전환은 상단 바 왼쪽 고정. 고른 계정 수를 항상 보여 주고, 검색이 되는 드롭다운.
- 페이지 폭 제한 없음(표가 넓다). 본문 글은 최대 72자 폭.

## 6. 컴포넌트

**버튼** — 높이 32, 글자 13/500, 좌우 12.
- primary: `primary` 바탕 흰 글자 — 화면당 1개(주 동작).
- secondary: 흰 바탕 `line-strong` 테두리 `ink` 글자 — 대부분의 동작.
- ghost: 테두리 없음 `muted` 글자, hover `subtle` — 표 안·툴바의 가벼운 동작.
- danger: 흰 바탕 `danger` 글자·테두리 — 삭제·해제. 실행 전 확인.
- 비활성: 50% 불투명 + `cursor-not-allowed`. 처리 중: 글자 유지 + 회전 표시, 중복 클릭 막기.

**입력·선택** — 높이 32, `line-strong` 테두리, 6px. 포커스 = `focus` 2px 링. 라벨은 항상 보이게(placeholder만으로 라벨 대신 안 함).
오류는 입력 바로 아래 `danger` 12px.

**배지(상태)** — 12/500, 4px, 좌우 6. 앞에 6px 점.
| 상태 | 모양 |
|---|---|
| ON·성공·승인 | `accent-soft` + `accent` |
| OFF·중지 | `subtle` + `muted` |
| 검수 중·실행 중·주의 | `warning-soft` + `warning` |
| 실패·반려·오류 | `danger-soft` + `danger` |
| 미리보기·안내 | `info-soft` + `info` |

**패널(카드)** — 흰 바탕, `line` 테두리, 8px, 그림자 없음. 머리 48px(제목 title-sm + 오른쪽 동작), 안 16px.

**표** — 업무의 중심.
- 머리: `subtle` 바탕, 12/600 `muted`, 고정(sticky). 정렬 가능한 칸은 ▲▼ 표시.
- 행: 40px, 아래 `line` 구분선, hover `subtle`, 선택 `primary-soft`. 줄무늬 없음.
- 숫자·금액·비율은 오른쪽 + `tabular-nums`, 단위(원·%)는 값 뒤.
- 첫 칸 체크박스(헤더는 전체 선택), 이름 칸은 넓게, 긴 글자는 말줄임 + 마우스 올리면 전체.
- 빈 표: "조건에 맞는 키워드가 없습니다" + 다음 행동(필터 지우기/등록하기).
- 불러오는 중: 행 모양 회색 막대(5줄). 오류: 표 위 `danger-soft` 줄.

**필터 바** — 표 바로 위. 검색(넓게) · 상태 · 범위 선택 → 적용된 필터는 칩(✕로 지움) + "모두 지우기".

**일괄 작업 바** — 행을 고르면 필터 바 자리에 나타남. `primary-soft` 바탕, "N개 선택됨 · 선택 해제" + 동작 버튼.
바꾸는 작업은 항상 미리보기 → 실행.

**KPI 타일** — 대시보드 위 한 줄. 라벨(caption muted) / 값(kpi) / 직전 기간 대비(▲▼ + %, 좋음 accent·나쁨 danger·변화 없음 faint).

**알림** — 페이지 위 줄 형태(info/warning/danger soft 바탕 + 글자색). 작업 완료는 오른쪽 아래 토스트 4초.

## 7. 하지 않는 것

- 보라·파랑 그라데이션, 유리 효과, 큰 히어로, 일러스트, 이모지 아이콘
- 모든 블록에 둥근 모서리 + 그림자, 색 띠(왼쪽 강조선) 카드
- 회색 위 회색 글자, 12px 미만 글자, 색만으로 상태 구분
- 다크 모드, 0ms로 확 바뀌는 상태, 과한 애니메이션

## 8. 접근성·점검

- 글자 대비 4.5:1 이상(위 표의 값 사용), 포커스 링 항상 보이게, 아이콘만 있는 버튼엔 `aria-label`
- 모든 동작 키보드로 가능, 클릭 영역 최소 28px
- 1280px(노트북) 기준 설계, 1024px에서 사이드바 접기, 표는 가로 스크롤
